Aide

Remplir un formulaire
Les champs interactifs du PDF apparaissent en bleu : touchez-les pour écrire.
Ajouter du texte
Outil Texte, puis touchez la page à l'endroit voulu.
Signer
Outil Signer : dessinez votre signature une fois, elle reste mémorisée.
Déplacer, agrandir
Faites glisser un élément ; tirez la poignée ronde pour le redimensionner. La barre qui apparaît permet de changer couleur et taille, dupliquer ou supprimer.
Modifier un texte
Touchez-le deux fois, ou bouton Modifier.
Zoomer
Écartez deux doigts sur le document.
Envoyer
Partager en haut à droite : mail, messagerie, « Enregistrer dans Fichiers »…
Confidentialité
Aucun fichier n'est envoyé sur Internet : tout est calculé sur l'appareil.
